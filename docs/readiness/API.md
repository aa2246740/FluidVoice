# Local API reference

Generated by `python3 tools/readiness/check.py --generate`; edit `openapi.json`, not this file.

The API is disabled by default. It accepts loopback clients only and has no HTTP authentication.
Any local process can access history or invoke providers after the user enables it.
Keep it disabled on shared machines; never log bodies, dictation text, paths or credentials.

Default endpoint: `http://127.0.0.1:47733`.

| Method | Path | Operation |
|---|---|---|
| GET | `/v1/health` | Read app health and version |
| GET | `/v1/history` | Read newest loaded dictation history |
| GET | `/v1/dictionary/replacements` | Read replacement rules |
| POST | `/v1/dictionary/replacements` | Append or replace dictionary rules |
| GET | `/v1/dictionary/custom-words` | Read boosted words and aliases |
| POST | `/v1/dictionary/custom-words` | Append or replace boosted words |
| POST | `/v1/transcribe` | Transcribe a local file, base64 audio or raw uploaded audio |
| POST | `/v1/postprocess` | Process text with the currently configured AI provider |

Requests are capped at 500 MiB. Responses close the connection. History timestamps use ISO 8601.
See `openapi.json` for request, response, status and nullable-field contracts.
